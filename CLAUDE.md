# squad-bot

A Telegram bot for one group chat of 7 friends who play CS2 and other games
together. It tags everyone, gathers players for a game, and keeps the group's
running jokes as stats.

## Working language

- Talk with Taras in Ukrainian.
- Code, commit messages, specs and docs in English.
- Everything the bot writes in the chat is in Ukrainian.

## How work runs

Features go through `/spec` (the spec-driven plugin, enabled at user scope).
Specs live in `docs/specs/`; the first one is `docs/specs/mvp/`.
